## Featured Projects

### Quality-Control Testing Application

An independently designed BossPac internal application built with Python/PyQt6 and Qt/QML for repeatable embedded-device verification, serial/UART communication, configuration checks, timed echo testing, and expected-response validation.

### Bifrost Automation System

An independent Linux and Raspberry Pi workflow-automation system built with Python, Playwright, and SQL. It supports member selection, room booking, email verification, scheduling, reporting, and database synchronization.

### Radio Survey Tool

An independently developed BossPac internal Python tool that processes Radio/DNET field-survey results and produces CSV reports and Google Earth-compatible geospatial visualizations for wireless-coverage analysis.

### Solar Car Dashboard System

A collaborative contribution to the University of Calgary Solar Car Team involving Qt/QML dashboard interfaces, real-time vehicle telemetry, embedded and electrical integration, system testing, soldering, and competition troubleshooting.
